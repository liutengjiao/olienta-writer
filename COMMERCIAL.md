The project author may distribute official compiled builds through:

Payment for an official build is payment for packaging, signing, distribution, maintenance, support, and convenience. It does not remove the open source rights granted by the source code license.

## Third-Party Distribution

Third parties may distribute modified or unmodified builds only if they comply with the open source license and the trademark policy.

In particular, third-party builds must not:

- Pretend to be the official Olienta Writer release.
- Use official Olienta branding in a confusing or misleading way.
- Hide source code obligations required by the open source license.
- Replace official support, update, or payment channels while presenting the build as official.

See `TRADEMARK.md` for brand usage rules.
