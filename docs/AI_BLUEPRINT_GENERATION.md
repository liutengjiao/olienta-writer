# AI 章节蓝图生成 v0.1

章节蓝图页新增「AI 生成草案」。

## 行为

- AI 只生成蓝图草案，不会直接保存。
- 草案会填入当前蓝图编辑框：本章目标、必须发生、禁止提前发生。
- 作者可以修改每一个字。
- 只有点击「保存并覆盖后续蓝图」后，才会写入本地 Markdown 并覆盖后续蓝图。

## 上下文

蓝图生成会读取：

- 当前章标题和现有蓝图。
- 作者输入。
- 已确认正文记录。
- 已确认事实库。
- 框架文件摘要。

## AI 约束

- 不得违背作者确认正文。
- 不得提前释放后续高潮。
- 每章只推进本章必要内容。
- 输出 JSON 后由系统解析为结构化蓝图。

## 降级

如果没有可用 AI Provider，或 Provider 未配置 API Key，系统返回本地占位蓝图草案，方便继续测试交互。
