# AI 框架文件生成 v0.1

「框架文件」页从只读卡片升级为可编辑工作区。

## 支持范围

第一版支持对已有框架 Markdown 文件生成草案：

- 故事前提
- 世界观
- 角色图谱
- 情节大纲
- 语言风格 / 本小说的特色
- 材料提炼

## 行为

- 选择左侧框架文件后，读取本地 `.md` 内容。
- 作者可以写任意长度的输入，不要求格式。
- 点击「AI 生成草案」只会把草案填入编辑器，不会自动保存。
- 作者可以修改每一个字。
- 点击「保存框架文件」后才写回本地 Markdown。

## 上下文

框架草案生成会读取：

- 当前框架文件用途。
- 作者输入。
- 当前文件已有内容。
- 已确认事实库。
- 其它框架文件摘要。

## 原则

框架文件可以被 AI 补全，但一旦作者保存，后续 AI 必须尊重保存后的本地 Markdown 内容。
