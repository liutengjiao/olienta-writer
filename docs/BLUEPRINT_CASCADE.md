# 蓝图级联覆盖 v0.1

Olienta 第一版采用“作者修改某章蓝图后，默认覆盖后续章节蓝图”的策略，避免长篇后续章节继续沿用旧因果链。

## 行为

点击「保存并覆盖后续蓝图」后：

1. 当前章旧蓝图会先备份到 `blueprints/history/{章节号}/vXXX.md`。
2. 当前章新蓝图写入 `blueprints/chapters/{章节号}.md`。
3. 后续章节旧蓝图逐章备份到 `blueprints/history/{章节号}/vXXX.md`。
4. 后续章节蓝图被重新生成并覆盖。
5. 最近一次覆盖记录写入 `blueprints/history/last-cascade.md`。

## 作者体验

- 不弹窗二次确认。
- 后续蓝图默认覆盖。
- 作者正式写每章正文时，会再次确认该章内容。
- 所有蓝图文件和历史文件都是本地 Markdown，可以在「本地文件」中查看。
- 保存蓝图会写入 `tasks/history.jsonl` 的 `blueprint_saved` 任务记录，方便在「任务 → 历史任务」回看。

## 当前限制

- 后续蓝图第一版用规则生成，尚未接入 AI 深度重写。
- 历史记录目前记录最近一次覆盖；完整版本通过每章 `vXXX.md` 保留。
