# 可编辑候选稿 v0.1

本轮将 AI 候选稿改为可编辑。

## 新行为

1. AI 生成整章后，内容进入“候选稿（未进入正文）”。
2. 候选稿不会自动覆盖正式正文。
3. 作者可以在候选稿区域逐字修改。
4. 修改候选稿时，系统会重新执行规则型冲突检查。
5. 作者点击“采用为正文”后，当前候选稿内容才写入正式正文。
6. 写入正文后，触发自动保存和事实抽取。

## 设计意义

这一步把“作者确认最大”落实到候选稿层：

- AI 只能给草稿。
- 作者可以改每一个字。
- 采用时才进入正式文本。
- 采用后的文本成为后续 AI 必须尊重的确认内容。

## 当前限制

- 候选稿只有一个版本。
- 清空后不可恢复。
- 还不能把候选稿另存为历史版本。
- 冲突检查仍是规则型，不是语义级。

## 下一步

1. 增加候选稿版本历史。
2. 增加采用方式：替换全文 / 追加到末尾 / 插入光标。
3. 增加语义级冲突检查。
4. 增加候选稿与正文 diff 对比。
