# 小说类型配置保存

本轮把小说类型分类从“展示库”推进为“可保存的项目配置”。

## 保存位置

类型配置写入当前项目：

`.olienta/genre-profile.json`

不直接改 `project.yaml`，方便后续升级，也避免破坏作者已有项目配置。

## 当前字段

产品显示口径：

- `literary`：严肃文学 / 文学小说定位。
- `qidianMale`：网络文学男频 / 商业长篇分类。
- `qidianFemale`：网络文学女频 / 女性向分类。
- `keywords`：作者自定义关键词，例如都市、现实主义、商战、医美行业。

说明：`qidianMale`、`qidianFemale` 是第一版历史兼容字段名。界面、文档和 AI 提示词不再显示为平台男频/女生，而统一显示为网络文学男频/网络文学女频。

## AI 使用方式

AI 整章生成提示词会读取作品类型，但优先级低于：

- 作者输入
- 已确认正文
- 事实库
- 章节蓝图
- 框架文件
- Skill 约束

类型只能帮助控制方向，不能覆盖作者确认内容。
