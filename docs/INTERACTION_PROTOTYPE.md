# Olienta 写作平台界面原型 v0.1

这个目录是第一版本地界面原型，不代表产品会做网页端。正式产品方向仍然是 Windows/macOS 桌面端，本地项目文件夹，Markdown 文件可见。

## 原型入口

打开：`prototype/index.html`

## 已覆盖页面

- 最近项目
- 写作工作台
- 纯写作模式
- 小说配置
- 章节蓝图
- 事实库
- Skill 管理
- Timeline Pro 锁定态

## 第一版交互规则

- 编辑器默认 Markdown 所见即所得。
- 正文和蓝图分开。
- 正文保存后自动抽取事实。
- 修改第 N 章蓝图后，不弹窗，默认覆盖重生成后续蓝图。
- 覆盖蓝图不覆盖正文。
- Skill 第一版只支持导入和选择。
- 基础版免费，Timeline Pro 付费解锁。
