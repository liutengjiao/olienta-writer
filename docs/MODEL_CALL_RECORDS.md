# 模型调用记录

日期：2026-05-13

## 文件位置

```text
logs/model-calls/history.md
```

这个文件记录模型调用摘要。它是普通 Markdown，作者可以直接打开查看；软件里的“模型调用 → 调用记录”会把它渲染成可读列表。

## 当前记录内容

- 调用时间。
- 调用任务，例如候选稿生成、Provider 测试。
- Provider 名称。
- 章节号。
- 输入文件路径，例如章节写作任务书。
- 输出文件路径，例如候选稿。
- 结果说明或降级原因。

## 安全边界

- 不记录 API Key。
- 不记录完整 Prompt。
- 不记录完整正文。
- 只记录本地路径和摘要，便于作者追溯生成来源。

## 后续

后续可以增加：

- 耗时。
- Token 用量。
- 费用估算。
- 模型温度和上下文长度。
- 调用失败重试记录。
