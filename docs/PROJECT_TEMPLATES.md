# 项目模板第一版

本轮在“新建项目”里新增项目模板。

## 当前模板

- 严肃文学长篇：框架文件更强调现实压力、人物复杂性、具体场景、物证、代价和关系压力。
- 网文长篇：框架文件更强调章节推进、悬念递进、爽点、信息释放节奏和高潮延迟。
- 空白项目：只创建基础结构和通用提示。

## 生成内容

不同模板会影响：

- `framework/04-plot-outline.md`
- `framework/06-style-and-uniqueness.md`
- 每章蓝图中的“模板提示”
- `project.yaml` 中的 `template` 字段

## 边界

模板只初始化项目，不会限制作者后续修改。作者确认的正文、蓝图、事实库和框架文件仍然最高优先。
