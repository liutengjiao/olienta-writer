## 必须继续遵守的产品约束

- Olienta 是桌面写作平台，永远不做网页端。
- 项目内容必须能直接以本地 `.md` 文件看到。
- 蓝图和正文必须分开。
- 章节蓝图下面有章节二级栏目。
- 草稿箱下面有章节二级栏目。
- 正文下面有章节二级栏目。
- 后续蓝图重生成时，默认覆盖后续章节蓝图，不弹窗确认。
- 第一版只做中文和英文。
- 基础版免费；收费只解锁时间轴及里程碑模块。
- 默认编辑器目标是 Obsidian 式 Markdown 所见即所得，同时保留普通 Markdown 文件。
- 正文保存后自动抽取事实进入事实库。
- “本地 Markdown”页只负责查看项目内 `.md` 原文；正式编辑仍回到对应模块，避免绕过确认、蓝图覆盖和事实抽取规则。
- Skill 第一版支持导入、长期启用/停用、临时启用和冲突提示。
