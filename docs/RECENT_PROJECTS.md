# 最近项目

Olienta 不使用数据库保存最近项目列表。

## 当前行为

- 打开项目或新建项目后，会把项目路径加入最近项目列表。
- 最近项目最多保留 12 个，界面默认展示前 6 个。
- 最近项目保存为本机普通 JSON 文件：`recent-projects.json`。
- 桌面端通过系统应用配置目录保存这个文件，例如 Windows 会落在当前用户的应用配置目录下。

## 设计原则

最近项目属于软件偏好，不属于作品正文。它不会写进小说项目文件夹，也不会影响作品迁移。

作品本身仍然完全由项目目录承载：Markdown、YAML 和 JSON 文件都可以直接查看和备份。
