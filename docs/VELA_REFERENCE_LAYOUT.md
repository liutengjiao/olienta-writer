# Vela 参考布局落实记录

本轮把 Olienta 第一版桌面界面调整为接近 Vela 的专业写作软件布局，但保留 Olienta 自己的产品规则。

## 四区结构

- 左侧栏目导航：这是小说项目的一/二级栏目树，不是固定工具图标栏。一级栏目和二级栏目在同一棵树里，点击一级项展开/收拢，不再单独拆出二级栏目栏。
- 中间工作区：继续承载写作工作台、蓝图编辑、框架文件、事实库和 AI 配置。
- 右侧 Agent：作为 AI 工作入口，但明确 AI 内容必须进入候选稿，作者采用后才算正文。
- 底部任务区与状态栏：预留给后续 AI 工作流进度、批量生成、事实扫描和蓝图覆盖任务。

主线一级栏目固定为：

- 小说设置
- 故事构架
- 章节蓝图
- 草稿箱
- 正文

故事构架二级栏目固定为：

- 故事前提
- 角色图谱
- 世界观
- 情节大纲
- 时间轴及里程碑

事实库、Skill、AI Provider、本地 Markdown、导出属于左侧栏目树底部的“工具与设置”二级入口，但不能挤掉主线栏目。时间轴及里程碑属于故事构架二级栏目，不再单独作为一级栏目。

## 已保留的 Olienta 原则

- 不做网页端，当前仍按 Tauri 桌面应用推进。
- 正文与蓝图分开。
- AI 生成整章进入候选稿，不直接覆盖正文。
- 作者可修改候选稿每一个字，采用后才写入正式正文。
- 章节蓝图修改后，默认覆盖后续蓝图。
- 时间轴与里程碑仍作为 Pro 模块，但入口归入故事构架二级栏目。

## 下一步建议

下一步应把中间编辑器从普通 textarea 升级为 Markdown 所见即所得编辑器，并保留纯写作模式。
