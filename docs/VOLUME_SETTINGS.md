# 分卷设置

日期：2026-05-22

分卷设置用于把长篇小说按卷组织。它不替代章节蓝图，也不替代情节大纲；它只定义每一卷覆盖哪些章节、卷名是什么、这一卷的阶段目标是什么。

## 入口

当前入口在：

```text
项目 -> 小说结构 -> 分卷设置
```

这里可以：

- 点击 `生成分卷`，按 `总章数` 和 `故事结构` 自动生成三卷、四卷或五卷。
- 点击 `增加卷`，手动补充分卷。
- 修改卷名、起始章、结束章和卷说明。
- 点击 `保存分卷`，写入项目内的 `.olienta/volumes.json`。

## 保存位置

分卷数据保存为项目文件：

```text
项目根目录/.olienta/volumes.json
```

这是项目配置文件，不是软件安装目录文件。它会跟随项目备份、迁移和导出。

## 使用位置

分卷会影响三个地方：

- 项目结构侧栏：章节蓝图和正文列表会按卷显示分隔标题。
- 蓝图生成上下文：生成某章蓝图时，会带入该章所属分卷、范围和卷说明。
- 导出：导出整书或正文时，会按卷插入卷标题。

## 生成规则

自动生成分卷时：

- `五卷结构` 生成 5 卷。
- `四卷结构` 和 `起承转合` 生成 4 卷。
- `三幕式` 生成 3 卷。
- 其他结构默认生成 4 卷。

自动生成只是起点。作者可以继续手动调整章节范围和卷说明。
