# 当前进度：后端范围检索

日期：2026-05-14

## 本步目标

上一版“检索范围”主要在前端过滤结果。这样在项目很大时会有风险：后端先搜索全项目，最多返回前 120 条，如果这些结果都来自无关文件，前端再筛选“导入资料”时可能漏掉真正需要的命中。

本步把检索范围下沉到后端文件扫描层，让本地检索从源头只扫描指定范围。

## 已完成

1. 新增后端范围检索
   - 新增 `search_project_text_files_scoped`。
   - 旧的 `search_project_text_files` 保留，默认等同于 `all`。

2. 支持范围
   - `all`：全部可读文本。
   - `imported`：导入资料。
   - `framework`：故事构架。
   - `manuscript`：正文、蓝图、候选稿。
   - `memory`：事实库、任务书、日志。

3. 前端接入
   - “本地全文检索”页会把当前范围传给后端。
   - 后端先按范围过滤文件，再读取内容和生成命中结果。

4. 错误保护
   - 后端会拒绝未知检索范围。
   - 避免前端传错参数时悄悄变成全项目搜索。

## 当前意义

范围检索现在更加可靠：

- “只搜导入资料”不会被正文或日志抢占结果数量。
- “只搜故事构架”不会被候选稿干扰。
- “只搜事实与任务”可以更准确地找作者确认边界和任务书材料。

这一步让后续“自动装配章节任务书”有了更稳的本地检索基础。
