# 当前进度：外部作品文件夹地图

日期：2026-05-14

本轮继续落实“作品内容不放在软件目录内”的方向。Olienta 现在不只把项目保存到软件外部，也在首页显示外部作品文件夹的文件地图。

## 已完成

- 首页在打开项目后显示“外部作品文件夹地图”。
- 文件地图按项目文件夹分组展示：
  - `framework/`：故事构架。
  - `blueprints/`：章节蓝图。
  - `manuscript/`：正文、候选稿、作者输入。
  - `facts/`：事实库与作者确认。
  - `characters/`：角色卡、关系图谱、成长线。
  - `timeline/`：时间轴及里程碑。
  - `knowledge/`、`skills/`、`tasks/`、`logs/`、`models/`、`exports/`。
  - `.olienta/` 与 `.olienta-events/` 作为本地配置和事件记录。
- 每个文件夹显示文件数量、文本体积、分类标签和部分可点击文件。
- 点击文件会进入现有本地 Markdown 读取流程，仍然不绕过正文、蓝图、框架文件的专门确认流程。

## 产品原则

- 项目文件夹就是作品本体。
- Olienta 读取并增强这个文件夹，但不把作者内容锁进软件内部。
- 这些文件夹可以被 Obsidian、VS Code、文件管理器、同步盘直接打开。
- 通用文件地图用于浏览和定位；正式写作仍回到对应模块，避免破坏作者确认、蓝图覆盖和事实抽取规则。

## 验证

- `npm run lint` 通过。
- `npm run build` 通过。
- 浏览器刷新后无前端控制台错误。
