# 当前进度：外部资料导入

日期：2026-05-14

## 本步目标

Olienta 的知识库不能是空概念。作者应当可以把外部 Markdown 或 TXT 资料导入当前作品项目，让这些资料成为项目文件夹内可见、可备份、可被 Obsidian 打开的普通文件。

## 已完成

1. 新增外部资料导入命令
   - 支持 `.md`、`.markdown`、`.txt`。
   - 导入时复制文件内容，不修改原始外部文件。
   - 目标目录固定为：

```text
knowledge/markdown/imported/
```

2. 文件名处理
   - 保留中文文件名。
   - 清理系统不允许的路径字符。
   - 如果重名，自动写成 `文件名-1.md`、`文件名-2.md`，不会覆盖已有资料。

3. 前端入口
   - “本地 Markdown”页标题动作区新增“导入资料”。
   - 同页新增“打开导入目录”，方便作者直接在系统文件夹中查看导入资料。
   - 导入成功后会自动打开导入后的文件预览，并刷新本地文件列表。

4. 本地检索准备
   - 导入文件进入项目文件清单。
   - 导入文件可以被本地全文检索读取。
   - 后续可被作者钉选进入章节写作任务书。

5. 事件记录
   - 每次导入写入 `tasks/history.jsonl` 和系统事件流，方便以后在“任务 / 日志”里追溯。

## 当前规则

- 导入资料属于当前作品项目，不属于软件安装目录。
- Olienta 不把资料藏进数据库。
- 第一版只导入单个 Markdown/TXT 文件。
- 更复杂的整文件夹导入、PDF/Word 解析、自动分块和向量索引，放到后续知识库增强阶段。
