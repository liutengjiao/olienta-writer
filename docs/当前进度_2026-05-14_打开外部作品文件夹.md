# 当前进度：打开外部作品文件夹

日期：2026-05-14

本轮继续落实“作品项目是软件外部的普通文件夹，可以被 Obsidian 等工具共享打开”的设计。

## 已完成

- 新增后端命令：`reveal_project_folder`。
- 首页项目入口增加“打开作品文件夹”按钮。
- 外部作品文件夹地图路径栏增加“在文件管理器中打开”按钮。
- 桌面端会调用系统文件管理器打开当前项目根目录：
  - Windows：Explorer
  - macOS：Finder
  - Linux：`xdg-open`

## 安全边界

- 必须先打开项目。
- 路径必须存在且是目录。
- 仍然拒绝 Olienta 软件目录内部路径，避免把软件工程误当小说项目。
- 该动作只打开文件夹，不修改任何作者内容。

- `npm run lint`：通过。
