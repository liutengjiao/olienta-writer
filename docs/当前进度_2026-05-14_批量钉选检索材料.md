# 当前进度：批量钉选检索材料

日期：2026-05-14

## 本步目标

本地全文检索已经能按范围找到材料，但写作时常常需要一次选中多条资料片段，统一加入当前章节任务书。单条点击太慢，也会重复装配任务书。

本步完成“批量钉选检索材料”。

## 已完成

1. 检索结果可多选
   - 每条检索结果前增加复选框。
   - 结果列表顶部增加“选择当前显示结果”。

2. 批量加入任务书
   - 新增“批量加入任务书”按钮。
   - 选中的多条结果会一次写入：

```text
tasks/pinned-context/当前章.md
```

3. 后端批量钉选
   - 新增 `pin_search_results_to_writing_brief`。
   - 多条材料写入后，只重新装配一次当前章节写作任务书。
   - 避免连续多次重建任务书。

4. 日志记录
   - 单条钉选仍记录 `search_result_pinned_to_brief`。
   - 批量钉选新增 `search_results_pinned_to_brief`，记录数量和来源。

5. 安全规则
   - 批量钉选必须至少选择一条结果。
   - 每条结果仍必须来自项目内可读文本文件。
   - 正文和作者确认规则不被绕过，钉选材料只进入任务书上下文。

## 当前意义

现在从知识库到写作任务书的链路更顺：

1. 导入资料或打开已有项目文件。
2. 按范围搜索。
3. 多选相关命中。
4. 一次加入当前章任务书。
5. 后续 AI 候选稿读取这些材料，但不能覆盖作者确认内容。
