# 当前进度：本地全文检索

## 本次推进

知识库里的“语义检索”先落地为第一版本地全文检索。

现在可以在当前项目文件夹内检索这些文本文件：

- Markdown：`.md`
- 纯文本：`.txt`
- JSON：`.json`
- JSON Lines：`.jsonl`

检索结果会返回：

- 文件分类
- 本地相对路径
- 命中行号
- 命中片段

点击结果后，会直接在中间栏打开对应文件预览。

## 设计原则

这一版仍然不引入数据库。项目里的正文、蓝图、草稿、事实库、任务书、日志、角色卡、Skill 和模型调用记录，继续以本地文件作为真实来源。

后续如果接入向量索引，也只能作为检索加速层，不能替代本地文件本身。
