# 当前进度：本地检索范围

日期：2026-05-14

## 本步目标

资料进入知识库以后，检索必须更贴近写作工作流。作者常常不是想搜整个项目，而是想只搜导入资料、只搜故事构架、只搜正文与蓝图，或者只搜事实库和任务书。

## 已完成

1. 检索页改名
   - 左侧知识库二级栏目从“语义检索”改为“本地全文检索”。
   - 这是当前真实能力：先从本地文件全文检索落地，后续再升级本地向量/语义索引。

2. 新增检索范围
   - 全部：项目内所有可读文本。
   - 导入资料：`knowledge/markdown/imported/`。
   - 故事构架：`framework/`。
   - 章节文本：正文、蓝图、候选稿。
   - 事实与任务：事实库、任务书、日志。

3. 检索状态更清楚
   - 显示当前检索范围。
   - 显示当前范围内有多少文件。
   - 搜索后显示范围内命中数量和当前显示数量。

4. 操作补强
   - 增加“清空”按钮。
   - 保留“打开文件”。
   - 保留“定位”。
   - 保留“加入当前章任务书”。

## 当前意义

本地全文检索现在可以直接服务章节写作：

- 想找旧设定，只搜故事构架。
- 想找参考资料，只搜导入资料。
- 想查前文，只搜章节文本。
- 想查约束，只搜事实与任务。
- 命中后可直接钉选进当前章写作任务书。
