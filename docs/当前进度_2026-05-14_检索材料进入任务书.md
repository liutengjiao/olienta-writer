# 当前进度：检索材料进入任务书

## 本次推进

知识库全文检索结果现在可以进入当前章写作任务书。

作者在“知识库 / 语义检索”里搜到事实、角色、伏笔、正文片段或蓝图片段后，可以点击“加入当前章任务书”。

系统会做三件事：

- 把该片段写入 `tasks/pinned-context/{chapter_id}.md`
- 重新装配 `tasks/writing-briefs/{chapter_id}.md`
- 在任务历史里记录 `search_result_pinned_to_brief`

## 为什么不直接写在页面状态里

候选稿生成时会重新装配写作任务书。如果只把检索片段临时放在前端状态里，下一次生成候选稿时会丢失。

所以钉选材料必须进入本地文件：

```text
tasks/
  pinned-context/
    001.md
  writing-briefs/
    001.md
```

这样后续无论重新装配任务书，还是生成候选稿，都能继续读到作者钉选的材料。

## 规则

- 钉选材料只是写作任务书上下文，不是正文。
- AI 必须读取钉选材料，但不能因为钉选材料覆盖作者已确认正文。
- 如果钉选材料和事实库、正文、蓝图冲突，后续候选稿审查必须提醒作者。
