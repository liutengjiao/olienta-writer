# 当前进度：知识库总览

日期：2026-05-14

## 本步目标

资料导入后，作者需要能快速看到知识库里已经有什么，而不是只能去文件夹里猜。知识库总览应该直接显示导入资料数量、体积、文件夹分布和最近导入文件。

## 已完成

1. 知识库总览工作面板
   - 显示导入资料数量。
   - 显示导入资料总体积。
   - 显示当前项目可读文件数量。
   - 明确资料位置：

```text
knowledge/markdown/imported/
```

2. 导入动作前置
   - 在知识库总览中直接提供：
     - 导入资料
     - 批量导入文件夹
     - 打开导入目录

3. 资料文件夹分布
   - 根据导入后的相对路径统计子文件夹。
   - 展示每个文件夹下有多少资料文件和占用体积。

4. 最近资料
   - 展示最近的导入资料文件。
   - 可以直接打开预览。
   - 可以直接在系统文件管理器中定位。

5. 检索结果补强
   - 本地全文检索结果新增“定位”按钮。
   - 作者看到命中文件后，可以直接回到系统文件夹查看原文件。

## 当前意义

知识库现在不再只是概念入口，而是一个可操作的本地资料中心：

- 资料能导入。
- 资料能看见。
- 资料能按文件夹统计。
- 资料能检索。
- 检索结果能进入任务书。
- 资料文件能被系统文件管理器定位。
