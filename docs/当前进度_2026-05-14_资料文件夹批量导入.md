# 当前进度：资料文件夹批量导入

日期：2026-05-14

## 本步目标

单个资料导入还不够。真实写作时，作者往往会有一整包参考资料、旧软件导出的 Markdown、人物设定笔记或行业材料。Olienta 需要能把一个资料文件夹批量导入当前作品项目，让知识库变成真正可用的本地资料区。

## 已完成

1. 新增“批量导入文件夹”
   - 位于“本地 Markdown”页标题动作区。
   - 选择一个外部文件夹后，递归扫描其中的 `.md`、`.markdown`、`.txt` 文件。
   - 复制到当前作品项目：

```text
knowledge/markdown/imported/
```

2. 保留文件夹层次

例如外部资料：

```text
资料夹/
  总览.md
  人物/
    杨志远.txt
```

导入后变成：

```text
knowledge/markdown/imported/总览.md
knowledge/markdown/imported/人物/杨志远.txt
```

3. 不覆盖已有资料
   - 如果同名文件已经存在，会自动写成 `总览-1.md`、`总览-2.md`。
   - 作者原有资料不会被覆盖。

4. 安全限制
   - 不能把当前作品项目自身作为资料文件夹导入，避免递归复制项目。
   - 跳过 `.git`、`node_modules`、`target`、`dist` 等无关目录。
   - 第一版只导入 Markdown/TXT，跳过 Word、PDF、图片等文件。
   - 单次最多导入 500 个支持文件，避免误选巨大目录。

5. 导入结果
   - 导入完成后刷新本地文件清单。
   - 自动打开最后一个导入文件的预览。
   - 提示导入数量和跳过数量。
   - 写入系统事件 `reference_directory_imported`。

## 与写作流程的关系

批量导入后的资料可以继续用于：

- 本地 Markdown 浏览。
- 本地全文检索。
- 检索结果钉选进入章节写作任务书。
- 后续知识库语义索引。
- AI 写作时作为可追溯的本地上下文来源。
