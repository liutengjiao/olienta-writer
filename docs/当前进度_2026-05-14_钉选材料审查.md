# 当前进度：钉选材料进入候选稿审查

## 本次推进

“作者钉选材料”现在不只进入任务书，也进入候选稿审查链。

当作者在知识库检索页把材料加入当前章任务书后，系统会保存到：

```text
tasks/pinned-context/{chapter_id}.md
```

候选稿审查时会读取该文件，并检查候选稿是否明显承接这些材料。

## 审查规则

候选稿审查新增一类风险：

- `钉选材料提醒`：候选稿没有明显承接作者钉选材料。
- `钉选材料风险`：候选稿触及钉选材料，同时出现否定表达，可能改写作者意图。

审查报告里也新增分组：

```text
作者钉选材料
```

前端候选稿审查面板也会把这类问题归入单独分组。

## 为什么这样做

作者钉选材料通常代表“这一章我明确想让 AI 记住或使用的东西”。

所以它的优先级应该高于普通搜索结果，也不应该只停留在任务书里。候选稿如果漏掉它，或者反着写，就应该提醒作者。
