# 当前进度：钉选材料管理

## 本次推进

这次把“检索结果加入任务书”继续推进成可管理的闭环。

现在已经完成：

- 知识库全文检索支持分类筛选。
- 检索结果可以加入当前章任务书。
- 当前章任务页会显示“钉选材料”列表。
- 每条钉选材料可以打开来源文件。
- 每条钉选材料可以移除。
- 移除后会重新装配当前章写作任务书。

## 本地文件结构

钉选材料仍然保存为普通 Markdown 文件：

```text
tasks/
  pinned-context/
    001.md
  writing-briefs/
    001.md
```

`tasks/pinned-context/{chapter_id}.md` 是作者手动钉选的检索材料。

`tasks/writing-briefs/{chapter_id}.md` 是最终给候选稿生成读取的本章任务书。

## 交互规则

- 作者从知识库检索页点击“加入当前章任务书”后，材料写入 `tasks/pinned-context/{chapter_id}.md`。
- 系统重新装配 `tasks/writing-briefs/{chapter_id}.md`。
- 作者在任务页点击“移除”后，材料从 `tasks/pinned-context/{chapter_id}.md` 删除。
- 系统再次重新装配任务书。
- 候选稿生成永远读取重新装配后的任务书，而不是读取前端临时状态。
