# 当前进度：页面内导入导出收拢

日期：2026-05-14

## 本步目标

导入、导出不应作为每个页面都常驻的全局按钮。它们必须出现在真正需要的页面标题动作区，和“编辑、预览、保存、AI 生成”等页面动作处在同一层。

这符合桌面写作软件的基本逻辑：当前页面负责当前动作，顶部 Logo 行只显示软件名和项目状态，不堆无关操作。

## 已完成

1. 移除页面框架的自动全局动作
   - `PageFrame` 不再自动给每个页面塞入“导入 / 导出”。
   - 每个页面只显示自己声明的操作按钮。

2. 小说设置页保留项目入口动作
   - 标题动作区增加“导入项目”。
   - 打开项目后显示“打开作品文件夹”和“AI 填充配置”。
   - 项目创建、打开、选择外部作品文件夹仍保留在小说设置页的“项目入口”表单中。

3. 首页入口去掉不合适的导出按钮
   - 首页继续负责打开本地项目、打开测试项目、打开作品文件夹。
   - 全书导出回到“导出”专页，不再在首页入口混杂出现。

4. 导出页形成完整闭环
   - 导出页标题动作区保留“导出 MD / 导出 TXT / 导出 Word”。
   - 新增“打开导出目录”。
   - 新增“定位最近导出”，导出成功后可直接在系统文件管理器中定位生成文件。
   - 页面中显示最近一次导出路径。

5. 导出结果状态
   - 导出成功后，软件记住最近导出的项目内相对路径。
   - 作者可以从导出页直接定位该文件。

## 当前规则

- 项目导入：放在“小说设置 / 项目入口”和首页入口。
- 全书、当前章、选中章节导出：放在“导出”页。
- 正文页只保留“导出本章 MD”这种局部轻入口。
- 顶部 Logo 行不放导入、导出、纯写作、AI 生成等动作。
- 后续新增页面时，按钮必须跟随页面职责，不做全局常驻。
