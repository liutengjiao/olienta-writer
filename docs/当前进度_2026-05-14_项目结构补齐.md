# 当前进度：项目结构补齐

日期：2026-05-14

本轮在项目健康检查之后，新增“补齐缺失结构”能力。

## 已完成

- 新增后端命令：`repair_project_structure`。
- 首页健康检查出现缺失关键项或建议项时，显示“补齐缺失结构”按钮。
- 补齐动作会：
  - 创建缺失目录。
  - 创建缺失基础文件。
  - 保留作者已有文件，不覆盖已有内容。
  - 重新刷新项目健康检查。
  - 重新刷新项目作品库清单、Markdown 列表、框架文件和 Skill 列表。
  - 写入系统事件：`project_structure_repaired`。

## 安全边界

- 不允许在 Olienta 软件目录内部修复小说项目。
- 不覆盖已有正文、框架、蓝图、事实库或 Skill。
- 如果 `project.yaml` 缺失，会根据文件夹名创建一个最小项目配置，用于恢复基础结构。
- 修复是非破坏性的，只做“缺什么补什么”。
