- `LocalFilesPanel`：本地 Markdown 分类浏览、打开、定位、编辑保存。
- `SkillPanel`：Skill 导入、启用/停用、临时启用、预览。
- `ModelCallsPanel`：模型调用记录、Provider 测试和历史入口。

### 2. 已串起的核心写作链路

当前主链路已经比较完整：

```text
本地资料导入 / 本地 Markdown
  -> 本地全文检索
  -> 检索结果钉选进当前章节任务书
  -> 任务书工作台编辑和装配
  -> 生成候选稿
  -> 候选稿审查、历史恢复、追加或替换
  -> 正文页作者确认保存
  -> 事实库重扫、作者确认日志、章节导出
```

### 3. 产品原则继续保留

- 本地 Markdown 文件仍是写作项目的源头。
- AI 输出只进入候选稿，不自动进入正文。
- 正文保存才视为作者确认。
- 候选稿进入正文必须由作者手动选择追加或替换。
- 事实库、伏笔、任务书、日志都仍是普通本地文件，可直接查看。
