# 当前进度：Provider 运行参数

本轮把 Provider 配置从基础连接信息推进到可控制运行边界。

## 已完成

- Provider JSON 支持 `contextWindow`、`maxTokens`、`timeoutSeconds`。
- 后端 OpenAI-compatible 请求会把 `maxTokens` 转成 `max_tokens` 写入请求体。
- 后端 HTTP 超时改为读取 `timeoutSeconds`，并限制在 5 到 300 秒之间，避免误填导致无限等待。
- `contextWindow` 作为模型能力记录保存在配置中，不写入 OpenAI 请求体。
- 新项目默认 Provider 模板补上上下文窗口、最大输出和超时秒数。
- Provider 面板新增“上下文窗口”“最大输出”“超时秒数”三个字段。
- Provider JSON 导出继续清空密钥，同时保留运行参数，方便迁移配置。
- smoke 和 Rust 测试覆盖运行参数：请求体包含 `max_tokens`，导出配置保留 `maxTokens` 和 `timeoutSeconds`。
