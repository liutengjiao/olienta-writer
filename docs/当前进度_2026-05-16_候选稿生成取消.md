# 当前进度：候选稿生成取消与过期结果保护

真实 Provider HTTP 调用接入后，候选稿生成可能等待较长时间。本轮补齐前端运行态，避免旧请求返回后覆盖当前章节。

## 已完成

- `App.tsx` 新增候选稿生成运行编号、运行状态和取消函数。
- 点击“生成候选稿”后会进入 `working` 状态，并显示当前正在请求的章节。
- 点击“取消生成”或切换章节时，会让当前运行编号失效；底层 Provider 请求即使稍后返回，也不会覆盖当前候选稿、审查路径或任务状态。
- 任务页、草稿箱和右侧 AI 助手都接入“生成中”禁用态和“取消生成”按钮。
- `dev-smoke` 增加取消生成入口契约，防止后续界面重构时丢掉这个保护。

## 说明

当前取消是前端级取消：它会忽略过期返回结果，但不能强行中断已经发出的 Tauri 后端 HTTP 请求。后续如果要做真正中断，需要给后端 Provider 调用增加任务 ID、取消表和更短的轮询/超时边界。
