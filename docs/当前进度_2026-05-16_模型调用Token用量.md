# 当前进度：模型调用 Token 用量

本轮把 OpenAI-compatible 响应里的 `usage` 解析进模型调用记录。

## 已完成

- Provider 调用返回值从纯文本升级为 `content + usage`。
- 后端解析 `usage.prompt_tokens`、`usage.completion_tokens`、`usage.total_tokens`。
- `logs/model-calls/history.md` 每条记录新增：
  - `promptTokens`
  - `completionTokens`
  - `totalTokens`
- Provider 测试、候选稿生成、章节蓝图草案、框架草案都会携带可用的 token 用量。
- 如果兼容网关没有返回 `usage`，日志中对应字段显示 `-`，不影响生成流程。
- Rust 定向测试已覆盖 usage 解析和日志写入。

## 验证

```powershell
cd app/src-tauri
cargo test openai_compatible_call_posts_chat_completion_request -- --nocapture

```

结果：三个定向测试均通过。
