# 当前进度：模型调用日志归一

本轮把章节蓝图和框架草案生成的模型调用日志补齐到和候选稿一致。

## 已完成

- 蓝图草案生成现在记录实际命中的 Provider 名称和模型，而不是固定的 `blueprint-provider-or-local-placeholder`。
- 框架草案生成现在记录实际命中的 Provider 名称和模型，而不是固定的 `framework-provider-or-local-placeholder`。
- Provider 返回空内容、调用失败或配置缺失时，日志会记录 `local-placeholder` 和明确降级原因。
- 新增通用草案生成结果结构，统一保存 `content`、`source`、`fallback_reason`。
- 新增 Rust 单测 `blueprint_and_framework_generation_log_selected_provider`，用本地 HTTP 假服务覆盖蓝图和框架两条生成链路。

## 验证

```powershell
cd app/src-tauri
cargo test blueprint_and_framework_generation_log_selected_provider -- --nocapture
```

结果：定向测试通过，模型调用日志不再出现旧的 provider-or-local-placeholder 占位名称。
