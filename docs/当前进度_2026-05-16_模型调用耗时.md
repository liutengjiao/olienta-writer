# 当前进度：模型调用耗时记录

本轮给模型调用记录补上耗时字段，方便排查 Provider 慢请求和失败降级。

## 已完成

- `ModelCallLog` 新增 `duration_ms`。
- Provider 测试、候选稿生成、章节蓝图草案、框架草案都会记录耗时。
- `logs/model-calls/history.md` 每条记录新增 `durationMs`。
- `docs/MODEL_CALL_RECORDS.md` 已同步当前记录字段。

## 说明

耗时从进入对应生成/测试函数开始计算，包含 Provider 选择、本地上下文装配、HTTP 请求和结果写入前的主要工作。它不是 token 级耗时，但足够用于判断请求是否异常变慢。
