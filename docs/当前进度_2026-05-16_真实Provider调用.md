# 当前进度：真实 Provider 调用

本轮把 OpenAI-compatible 调用入口从本地占位响应升级为真实 HTTP 请求。

## 已完成

- `call_openai_compatible_with_system` 现在会向 `{baseUrl}/chat/completions` 发送 `POST` 请求。
- 请求体包含 `model`、`temperature` 和 `messages`，其中 system prompt 会进入 `role: system`，用户输入会进入 `role: user`。
- 非 Ollama Provider 仍要求 API Key；远程调用会使用 `Authorization: Bearer ...`。
- 响应解析 `choices[0].message.content`，兼容部分返回 `choices[0].text` 的网关。
- HTTP 失败、非 2xx、无有效 content 或 JSON 无效时返回明确错误，上层候选稿链路仍会降级成本地候选稿。
- Rust 单测新增本地 HTTP 假服务，验证请求路径、Authorization、模型、温度和 messages 结构。
- 候选稿 Provider 路由测试改为读取假服务返回的真实内容，确认候选稿不再依赖占位文本。
