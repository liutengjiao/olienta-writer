# 当前进度：章节 Provider 路由

本轮把候选稿生成从固定本地占位推进到读取 `chapter` 用途的 Provider 选择结果。

## 已完成

- `generate_candidate_draft` 仍先装配章节写作任务书，保证 AI 输入来自本地 Story System 合同。
- `generate_candidate_content` 现在会按 `.olienta/ai-providers.json` 的顺序选择 `useCases: ["chapter"]` 的启用 Provider。
- 命中 Provider 后，候选稿内容来自统一的 OpenAI-compatible 调用入口，模型调用日志和任务历史记录实际 Provider 名称。
- Provider 返回空内容或调用失败时，仍降级成本地占位候选稿，并把降级原因写入候选稿审查提醒。
- 新增 Rust 单测 `candidate_generation_uses_chapter_provider_when_available`，覆盖候选稿正文、审查提醒、模型调用日志和任务历史中的 Provider 记录。
