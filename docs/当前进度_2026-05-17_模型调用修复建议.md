# 当前进度：模型调用修复建议

日期：2026-05-17

## 这一步完成

- 错误归因分类器现在同时返回修复建议。
- 失败诊断区的“错误归因”卡片会显示对应建议。
- 单条失败调用记录下方会显示建议提示。
- 修复建议覆盖：
  - 鉴权：检查 API Key、权限、保存后重测。
  - 配额：检查余额、账单、额度，必要时切换 Provider。
  - 限流：降低请求频率或切换限额更高的 Provider。
  - 超时：增大超时秒数、检查网络、降低上下文和最大输出。
  - 网络：检查 Base URL、代理、DNS、证书。
  - 返回格式：检查 OpenAI-compatible `chat/completions` 返回结构。
  - Provider：检查模型名、Base URL、接口路径和用途支持。
  - 未知：打开原始日志并结合 Provider 后台定位。
- 逻辑 smoke 新增修复建议覆盖。
- dev smoke 新增 `model-call-advice` 覆盖。
