# 当前进度：模型调用费用估算

日期：2026-05-17

## 这一步完成

- Provider 配置新增成本字段：
  - `inputPricePerMillionTokens`
  - `outputPricePerMillionTokens`
- 新建项目的默认 `.olienta/ai-providers.json` 会包含这两个字段，默认值为 `0`。
- AI Provider 页面新增两个价格输入框，作者可以按模型填写每百万输入/输出 Token 的美元价格。
- 模型调用页会读取调用日志中的 `promptTokens`、`completionTokens`，匹配 Provider 配置后估算费用。
- 模型调用摘要新增“预估费用”。
- 单条调用记录新增“费用”字段。
- Provider 导出仍会保留价格字段，但继续清理 `apiKey` 和 `apiKeyEncrypted`。

## 估算规则

- 输入成本 = `promptTokens / 1_000_000 * inputPricePerMillionTokens`
- 输出成本 = `completionTokens / 1_000_000 * outputPricePerMillionTokens`
- 总成本 = 输入成本 + 输出成本
- 如果日志没有 token 用量，或 Provider 没有填写价格，则该条调用不参与费用估算。
- 这是本地估算，不代表 Provider 官方账单。
