# 模块框架栏

日期：2026-05-13

## 定义

最左侧窄栏是 Olienta 的一级模块框架，不是项目结构树本身。

项目结构树是第二栏，只在“项目结构”模块下出现。小说设置、故事构架、章节蓝图、草稿箱、正文都属于“项目结构”模块，不应该被拆到最左侧窄栏里。

## 顶部模块

- 首页：项目入口、最近项目、本地项目状态。
- 项目结构：小说设置、故事构架、章节蓝图、草稿箱、正文。
- 知识库：事实库、本地 Markdown、Skill、后续语义检索。
- 角色：角色卡、关系图谱、角色成长线。它不同于项目结构里的“角色图谱”框架文档。

## 底部模块

- 任务：AI 工作流、写作任务书、候选稿审查、导出、事实抽取、蓝图重生成等任务。
- 日志：作者确认、候选稿采用确认、正文保存、蓝图覆盖、导出、事实抽取等事件记录。
- 模型调用：AI Provider、模型测试、调用记录。

## 当前实现

- “项目结构”模块保留原来的项目树。
- 其它模块拥有独立第二栏和中间展示页。
- 知识库二级页：知识库总览、事实库、本地 Markdown、Skill、语义检索。
- 角色二级页：角色总览、角色列表、关系图谱、成长线。
- 任务二级页：当前任务、历史任务。
- 日志二级页：作者确认日志、系统事件。
- 模型调用二级页：AI Provider、调用记录、连接测试。

## 本地文件联动

模块页的“文档预览”必须读取真实项目文件，不使用固定假数据。

- 任务页会读取 `tasks/current.json`、`tasks/writing-briefs/*.md`、`manuscript/candidates/reviews/*.md`。
- 历史任务会读取 `tasks/history.jsonl`、`logs/system-events.jsonl`、`logs/confirmations/*.md`。
- 日志页会读取 `logs/author-confirmation.md`、`facts/author-confirmation.md`、`logs/confirmations/*.md`。
- 知识库会读取 `facts/*.md`、`knowledge/*.md`、`skills/selected/*.md`。
- 角色页会读取 `framework/03-characters.md`、`characters/cards/*.md`、`characters/relations.md`、`characters/growth.md`；并可从角色图谱抽取角色卡。
- 模型调用会读取 `.olienta/ai-providers.json`、`logs/model-calls/history.md`、`models/README.md`。

## 约束

- 窄栏点击先切换一级模块。
- 第二栏展示该模块的二级结构。
- 中间栏展示该模块当前页面。
- 项目结构里的二级栏目不能被当成窄栏一级模块的替代品。
- 任何页面如果展示本地文件，都必须说明保存边界：正文、蓝图、故事构架走专门确认流程；模块辅助文档和事实约束可以从模块页保存。

完整文件模型见 `docs/LOCAL_PROJECT_MODEL.md`。
